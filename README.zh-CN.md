# AlbumWinnow

[English](README.md) · 简体中文

AlbumWinnow 是面向 macOS、iOS 和 iPadOS 的原生照片整理工具。项目计划在系统照片图库和用户选定的文件夹中查找重复照片，推荐保留版本，并让用户在清理前逐组核对。

## 项目状态

AlbumWinnow 正在开发 v1.0。开发版面向 macOS 26、iOS 26、iPadOS 26 及以上版本，可扫描已授权的照片图库和文件夹，将重复照片分组，并支持核对后移入可恢复位置。

## 构建与运行

在 Xcode 中打开 `AlbumWinnow.xcodeproj`。运行 macOS 版时选择 **AlbumWinnow**，运行 iPhone 或 iPad 模拟器时选择 **AlbumWinnowMobile**。在 **Settings** 的 **Scan Sources** 页面启用照片图库或添加文件夹，再回到重复项页面点击 **Scan**。

也可以用 `swift build --package-path Packages/AlbumWinnowCore` 独立构建共享 Swift 包。

## v1.0 范围

- 扫描系统照片图库和用户选定文件夹中的可访问照片，支持跨来源匹配。
- 识别完全重复的文件，以及同一画面在不同分辨率、压缩质量或编码格式下的副本，覆盖 HEIC、JPEG 和 PNG 等格式。
- 将匹配项分组供用户并排对比，结合画质、分辨率及 Live Photo 配对视频、编辑前原件等关联数据推荐保留版本。
- 复用未变化资源的扫描结果，在照片新增、编辑或删除后更新索引。

扫描会读取本地可用的图库资源，并在 Scan Issues 列出仅存于 iCloud 的照片。点击 **Download Pending Photos from iCloud** 可授权下载并重试这些项目。重复项页面分别显示 iCloud 下载和扫描进度，并列出可用、失败和待处理数量。扫描结束后，重复项概览以瀑布流显示分组封面。点开一组即可在组内核对照片。在设置里打开 **Show Filenames in Review** 可显示文件名。可以逐组勾选不需要的副本，再回到重复项概览，通过 **Confirm Cleanup** 一次确认整批项目。清理历史会记录每项结果。在 iOS 和 iPadOS 上，中断的扫描会在回到前台后按已保存来源续扫，并复用缓存的指纹。连拍中不同帧等视觉相似照片的整理功能计划在 v1.1 加入。

## 匹配与清理

| 类别 | 判定依据 | 清理行为 |
| --- | --- | --- |
| 完全重复 | 文件字节一致，或经过验证确认像素一致。 | 可在核对后清理。 |
| 可能是同一画面 | 像素比较显示不同分辨率、压缩质量或格式的图片可能来自同一画面。 | 对比细节后再选择要清理的副本。 |
| 视觉相似 | 分别拍摄的照片，表情、动作或构图有差异。 | 仅提供整理建议，计划在 v1.1 加入。 |

匹配和索引在设备上执行，本地可用的照片支持离线扫描。每次清理均需用户明确确认。确认后，图库照片移入「最近删除」，目录文件移入可用的文件系统回收站。文件提供方缺少回收站时，应用会保留原文件并记录失败。

## 技术设计

`AlbumWinnowCore` 计划以 Swift Package 形式供各平台的 SwiftUI 应用共享。PhotoKit 和 Foundation 分别用于访问系统图库和文件。BLAKE3 用于筛选字节一致的候选，pHash 和 dHash 用于检索视觉候选，再通过 Vision 特征描述和像素比较独立验证。SQLite 和 GRDB 存储指纹与扫描状态，Swift Concurrency 控制同时解码的图片数量。

## 开发路线

1. 实现重复识别原型，使用带标注的图片对验证分类。首项验收使用同一画面的 4032 × 3024 和 1280 × 960 两个版本，分别采用不同编码，验证两者能否归为同一画面。同一连拍中有内容差异的帧须排除在重复项清理结果之外。
2. 实现 macOS 文件夹扫描、候选索引和增量缓存。
3. 接入 PhotoKit，跟踪图库变化，并处理 Live Photo 和 iCloud 资源。
4. 使用 SwiftUI 实现 macOS 上的分组核对与清理流程。
5. 适配 iOS 和 iPadOS 的权限、后台执行限制和界面布局。
6. 对 1 万、5 万和 10 万张照片测量扫描耗时、峰值内存和匹配准确率，在发布前验证两类来源的清理流程。

单次扫描的设计目标为 10 万张照片，性能验证安排在最后一个阶段。
